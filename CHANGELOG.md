# Changelog

## 0.1.0

Initial release of the native offline Python library for EU AI Act calculation
and logic rules. Includes explicit unknown and unresolved states, traceable
results, local data mapping, batch evaluation and synthetic company examples.

The catalogue contains 1662 logic rules, 104 calculation rules and 545 duty
records. Versioned source context and documented interpretation limits remain
explicit; an individual result is not an overall conformity assessment.
